## Project Overview
RaceDay is a comprehensive web-based platform designed to streamline the organization, enrollment, and results tracking for sporting events. The system provides structured workflows for event organisers to host races and for participants to search, enroll, and view race outcomes seamlessly.

### Core User Roles
1. **Organiser:**
   - Responsible for creating and managing events and categories.
   - Handles administrative tasks and inputs final race results for participants.

2. **Participant:**
   - Registers and manages a user profile.
   - Browses upcoming events, enrolls in specific race categories, and views past completion times/results.
